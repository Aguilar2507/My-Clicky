# Quickstart: Apple Look

`swift build && swift run MyClickyChecks`, then `./build.sh && open ~/Applications/MyClicky.app`.

1. **Light Mode** (System Settings → Appearance → Light): open the notch. White/light gray app, black titles, gray
   text, blue selection. Walk Home, a conversation, all 8 Settings pages, Spending, and Settings → General → Replay the
   welcome tour.
2. **Dark Mode**: switch while Clicky is open. Everything turns dark, no restart.
3. **Accent**: set System Settings → Appearance → Accent to purple. Switches, selection and primary buttons turn purple.
4. **Buttons**: a Clicky's ⋯ → Delete…: hover Delete (red), Cancel (green). Hover primary/secondary buttons: fills
   change.
5. **Window buttons**: in the notch, hover the three dots (×, −, arrows appear). Green → full-screen window. Exit full
   screen, yellow → Dock. Reopen from the Dock, red → closes. In the notch, red and yellow tuck it back.
6. **Popovers**: ⌃⌥ ask something (bubble), double-tap ⌃ (text box): both match the appearance.
