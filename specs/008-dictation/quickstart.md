# Quickstart: Dictation

1. `swift build`, then `swift run MyClickyChecks` (dictation groups pass).
2. Copy something distinctive to the clipboard (e.g. "CLIPBOARD-TEST").
3. In each of Notes, Safari (a text field), Slack, VS Code and Mail: hold ⌃fn, say a sentence, release → inserted with
   correct spacing. Afterwards, ⌘V pastes "CLIPBOARD-TEST" (clipboard restored).
4. Focus a password field (Safari login) → refused with a notice.
5. Click the desktop (no field) and dictate → the notice says it's copied, and ⌘V pastes the transcript.
6. Hands-free: double-tap ⌃fn, talk ~2 minutes, double-tap → all inserted. Esc cancels.
7. Auto-detect: 5 English + 5 Spanish sentences → count correct (target ≥ 9).
8. Add "Anthropic" and "Jose" to WORDS → dictated with exact spelling.
9. Push-to-talk in Spanish uses the same language settings.
10. Compare the Dictation page with ref 06.
