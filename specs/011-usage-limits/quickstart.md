# Quickstart: Spending and Limits

1. `swift build`, then `swift run MyClickyChecks` (usage groups pass).
2. Ask 5 questions (incl. one "where is…"). The footer total grows, and the sheet's splits add up. Sonnet appears under "By model".
3. Set the budget to $0.05 → keep asking → 80% notice once → at 100% the next question is blocked with the button →
   "Allow $2 more" → questions work.
4. Agents still run while blocked (009).
5. Enter credit $20 since today → "≈ $… left" and a projection.
6. After a week of normal use, compare the month total with console.anthropic.com → Usage (within 5%). Record it here.
