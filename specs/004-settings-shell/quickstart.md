# Quickstart: Settings Shell

1. `swift build`, then `swift run MyClickyChecks` (Shortcut groups pass).
2. Build and open. Grant Input Monitoring when asked (System Settings → Privacy & Security → Input Monitoring).
3. Open the notch → gear (or right-click → Settings…). Compare with refs 03 and 07.
4. General: toggle Show in Dock (the icon appears and disappears). Change the API key (masked afterwards). Revoke Screen
   Recording and see ✗. Open → the right pane. What's new sheet shows the changelog.
5. Show in screen recordings OFF → record with QuickTime (File → New Screen Recording) while the notch panel is open.
   Note whether MyClicky appears, and record the result in the notes below.
6. Shortcuts: hold fn → listening starts (before 007 lands, this is the v0.1 talk flow). Change Push to talk to
   ⌥ option, and it works. Bind Text mode to ⌥ option → "Already used". Reset to defaults.
7. Type for 5 minutes in Notes using ⌃A, ⌃E and fn-arrow keys → no MyClicky triggers.
8. The old menu bar icon is gone.
