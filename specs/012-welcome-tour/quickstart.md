# Quickstart: Welcome Tour

1. `swift build`, then `swift run MyClickyChecks` (tour groups pass).
2. Back up and remove the data folder: `mv ~/Library/Application\ Support/MyClicky ~/Desktop/MyClicky-data-backup`.
   Remove the key from Keychain (Keychain Access → search "com.myclicky.anthropic") if you want a true fresh start.
3. Launch → the welcome window. Time the run (target < 10 min to the first answer).
4. Grant each permission and watch the ✓ appear. Relaunch when prompted. The tour resumes.
5. API key: a wrong key shows the error, and the right key shows "Key works".
6. Claude Code: skip, or check. Hands-on: each action ticks.
7. Interview: answer the three questions → three relevant Clickys appear (note your judgment here).
8. Settings → General → Replay → complete it → three more Clickys, and the old ones stay.
9. Restore your data folder when done testing, if you want your old chats back.
